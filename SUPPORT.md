# Getting help / Como obter ajuda

## English

- Start with the [README](README.en.md) and the guides in [`docs/en/`](docs/en/).
- Search existing issues; if nothing matches, open a bug report or feature
  request using the issue forms.
- Security problems: see [SECURITY.md](SECURITY.md) — do not open a public issue.

Please include a minimal reproduction and never paste secrets or private memory.

## Português do Brasil

- Comece pelo [README](README.md) e pelos guias em [`docs/pt-BR/`](docs/pt-BR/).
- Pesquise as issues existentes; se nada servir, abra um relato de bug ou
  solicitação de recurso pelos formulários.
- Problemas de segurança: veja [SECURITY.md](SECURITY.md) — não abra issue pública.

Inclua uma reprodução mínima e nunca cole segredos ou memória privada.
